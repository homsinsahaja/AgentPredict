How it works

  • Each UTC day is one round. The reference price is the Chainlink BTC/USD price when the round opens.
  • Only wallets holding an Agent ID can vote. Your Agent ID is checked on-chain — no account, no sign-up.
  • When the first vote of a new day arrives, the previous round resolves against the current Chainlink price. A tie counts as Up.
  • Your previous day's points are collected automatically when you vote again, or with the “Collect pending points” button.
